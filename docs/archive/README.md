# Archived Documentation

This folder contains historical implementation notes, summaries, and superseded documentation that have been moved from the main docs folder.

## Why Archive?

These documents were archived because they:
- Are implementation/development notes not needed for regular use
- Have been superseded by updated documentation
- Contained overlapping content that was consolidated
- Were completion summaries for implemented features

## Categories

### Implementation Notes
- `*_IMPLEMENTATION.md` - Technical implementation details
- `*_SUMMARY.md` - Feature completion summaries
- `*_analysis.md` - Technical analysis documents

### Superseded Guides
- `VISUALIZATION_*.md` - Consolidated into [HTML_VISUALIZATION.md](../HTML_VISUALIZATION.md)
- `CALIBRATION_*.md` - Consolidated into [CALIBRATION_GUIDE.md](../CALIBRATION_GUIDE.md)

### Historical Records
- `v223_IMPLEMENTATION_SUMMARY.md` - v2.2.3 changes (see CHANGELOG.md)
- `SUCCESS_SUMMARY.md` - Feature completion record

## Need Something?

If you need information from an archived document:
1. Check if the content exists in the current documentation
2. If not, the archived document is still available here
3. Consider if the archived content should be restored
